# ПОСЛЕДНЯЯ ИГРА — расширенный 3D-прототип

Проект Godot 4 для Windows и Android. Это исходный проект, а не уже собранные `.exe` и `.apk`.

## Уже реализовано
- 3D-комната от первого лица: кровать, стол, компьютер, дверь, освещение.
- WASD + мышь на ПК; сенсорный look-жест и экранные кнопки движения на телефонах.
- Взаимодействие с компьютером.
- Меню ретро-архива.
- Играбельный мини-Тетрис: перемещение, вращение, падение, очистка линий.
- Скоростной мини-уровень с прыжками через препятствия.
- Платформер с прыжками, платформами и собираемыми звёздами.
- Сюжетная сцена после прохождения трёх игровых миров.

## Запуск на ПК
1. Установить Godot 4.3+ (лучше актуальную стабильную Godot 4.x).
2. Распаковать ZIP.
3. В Godot Project Manager выбрать Import и указать `project.godot`.
4. Запустить F6/F5.
5. WASD — ходьба; мышь — осмотр; E — компьютер; Esc — отпустить мышь.

## Android
1. Установить Godot 4.x и настроить Android SDK/JDK по официальной инструкции Godot.
2. В Editor → Manage Export Templates установить шаблоны экспорта.
3. Project → Export → Add… → Android.
4. Указать Android SDK/JDK и экспортировать APK.
5. На телефоне: экранные кнопки движения, свайп по правой части экрана для осмотра, кнопка ДЕЙСТВИЕ для взаимодействия.

## Windows EXE
Project → Export → Add… → Windows Desktop, затем Export Project. Установить Windows export template, если Godot попросит.

## Ограничения текущей сборки
Это расширенный вертикальный срез: базовые игровые циклы уже есть, но пока используются процедурные примитивы и простые UI-мини-игры вместо финальных 3D-моделей, анимаций, озвучки и профессиональных кат-сцен. Готовые `.exe` и `.apk` не приложены: их нужно собрать в Godot на машине с настроенными экспортными инструментами.
