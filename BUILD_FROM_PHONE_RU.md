# Сборка игры только с телефона (облачная сборка)

Этот проект подготовлен для сборки через GitHub Actions. Компиляция выполняется на серверах GitHub, не на телефоне.

## Шаги
1. Скачайте ZIP проекта на телефон и распакуйте его в файловом менеджере.
2. Откройте https://github.com/ и создайте бесплатный аккаунт или войдите.
3. Нажмите **New repository**, назовите его `poslednyaya-igra`, выберите **Public** (для бесплатных GitHub Actions) и создайте репозиторий.
4. На странице репозитория нажмите **Add file → Upload files**. В файловом менеджере выберите ВСЕ файлы и папки внутри `poslednyaya_igra_full_project` (включая скрытую папку `.github`, если файловый менеджер показывает скрытые файлы). Перетащите/добавьте их в корень репозитория и нажмите **Commit changes**.
5. Откройте вкладку **Actions** в репозитории. Если GitHub спросит разрешение на запуск workflows, нажмите разрешить.
6. Выберите workflow **Build game installers** и нажмите **Run workflow**. Можно также дождаться автоматического запуска после загрузки файлов.
7. Дождитесь завершения двух задач `android` и `windows` с зелёными галочками.
8. Откройте завершённый запуск workflow, прокрутите до **Artifacts** и скачайте `poslednyaya-igra-android-apk` для телефона и `poslednyaya-igra-windows` для ПК. На Android распакуйте скачанный ZIP-архив артефакта, откройте APK и разрешите установку из этого источника, если Android спросит.

## Важно
- Сборка выполняется в облаке; Godot на телефоне не нужен.
- Для загрузки проекта удобнее открыть GitHub в браузере телефона и включить «Версия для ПК».
- В репозиторий загружайте содержимое папки проекта, а не ZIP-файл целиком.
- Если папка `.github` скрыта и не загружается, workflow не появится во вкладке Actions. Включите показ скрытых файлов.
- Это пробная сборка прототипа. Перед публикацией в Google Play потребуется отдельная настройка подписи релизного приложения.
